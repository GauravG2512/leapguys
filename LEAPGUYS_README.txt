LEAPGUYS — FIVE DISTINCT LEVELS
================================

LEVEL 1 — GARDEN RUN
- Beginner course. One jump per airborne sequence.
- Flat-ish winding route and basic jumps only.
- Uses large square, standard, medium and circular grass platforms.
- No moving or falling platforms.

LEVEL 2 — DOUBLE / TRIPLE LEAP
- Fixed platforms only.
- Player can jump up to three times before landing.
- Two double-jump gaps and three longer triple-jump gaps are designed into a canyon-style route.

LEVEL 3 — DRIFTING SWITCHBACKS
- Different, rising S-shaped route.
- Several original platform models move gently on X, Y and Z axes.
- Circular platforms remain in the route, with a fixed circular checkpoint.

LEVEL 4 — FALLING TRAIL
- Existing falling-platform asset appears at marked route positions.
- Fixed circular checkpoint and round platform in the later section.
- Moving platforms are not introduced yet; this level focuses on collapsing tiles.

LEVEL 5 — SKY RUINS
- Longest route (21 landing platforms) with two checkpoint islands.
- Combines triple jumps, drifting platforms and the original falling platforms.
- Includes standard, medium, large square and circular grass platforms.

ASSETS AND UI
- Uses the existing Kenney platform models and textures; no generic box obstacles added.
- A circular grass platform is present in every level.
- Retains third-person mouse camera, restart key, checkpoint respawn, HUD cleanup and supplied Thank You ending image.
- Splash-screen image is configured as the project icon.

CONTROLS
WASD: move
SPACE: jump (repeat while airborne for double/triple jump where available)
R: restart the current level
Hold RIGHT MOUSE BUTTON and move mouse: rotate camera
Mouse wheel: zoom
ESC: release mouse capture

RUN
1. Extract this ZIP into a new folder.
2. In Godot 4.7.2 Project Manager, click Import.
3. Select project.godot inside the LEAPGUYS folder.
4. Open the project and press F5.

TEST STATUS
Archive integrity and static route geometry/code checks are run before delivery. Actual Godot physics still requires a runtime playtest on a system with Godot installed.
