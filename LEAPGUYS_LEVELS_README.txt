LEAPGUYS - ENHANCED LEVEL EDITION
=================================

This update is built on the original LeapGuys/Kenney 3D platformer project and retains the original player, animation, environment, coins, and falling-platform scenes.

HOW TO OPEN
1. Extract this ZIP to a new folder.
2. In Godot 4.7.2 Project Manager choose Import.
3. Select project.godot inside the LEAPGUYS folder.
4. Import, open, and press F5 to run the project.

CONTROLS
WASD: move
SPACE: jump (double jump supported by original player controller)
R: restart the level
Arrow keys: rotate the camera
+ / -: zoom camera

LEVELS
1. Beginner's Leap: zigzag route, coins, falling platforms, checkpoint, moving hazard.
2. Moving Trials: longer route, more height changes, multiple moving hazards and falling platforms.
3. Skyfall Challenge: narrow platforms, elevated zigzag course, more hazards and coins.

Reach the flag to complete a course and unlock the next one. Checkpoints save a respawn position within the current run. Unlock progress is saved locally by Godot.

This is a Godot project ZIP, not a standalone EXE. Let Godot finish importing the 3D assets on first open.
